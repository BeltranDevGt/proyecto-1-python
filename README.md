# Proyecto 1: Python - Daxus

Repositorio correspondiente al primer proyecto práctico desarrollado bajo la guía y mentoría de **Daxus**. Este proyecto forma parte del proceso de aprendizaje técnico, aplicando fundamentos de programación en Python y buenas prácticas de desarrollo.

## 📂 Estructura del Repositorio

El proyecto contiene los siguientes archivos principales:

* **`proyecto.ipynb`**: Cuaderno de Jupyter principal donde se desarrolla la lógica, análisis e implementación del proyecto en Python.
* **`Presupuesto.pdf`**: Documento de referencia con la estructura de costos, requerimientos o lineamientos del presupuesto manejado en el proyecto.
* **`Template.png`**: Plantilla visual o esquema de diseño utilizado como referencia para la estructuración y presentación de resultados.
* **`README.md`**: Documentación principal del repositorio.
